# 🎧 DocVoice

**Читает книги и документы вслух человеческим голосом — без интернета.**
Слушайте сразу или сохраните аудиокнигу в MP3, разбитую по главам.

DocVoice открывает PDF, Word, EPUB, FB2 и ещё десяток форматов, сам вычищает из текста
мусор (номера страниц, колонтитулы, сноски, ссылки), правильно читает числа, сокращения
и ударения — и озвучивает это нейросетевыми голосами, которые работают прямо на вашем
компьютере. Интернет нужен один раз — чтобы скачать голоса.

Программа делалась с прицелом на людей, которым тяжело читать с экрана: крупный
масштаб интерфейса, простой режим с минимумом кнопок и подробная
[инструкция для начинающих](docs/Инструкция.txt).

## Возможности

**Форматы.** PDF, DOCX, DOC, ODT, RTF, TXT, Markdown, HTML, EPUB, FB2 (и `.fb2.zip`), PPTX, DjVu.

**Три движка синтеза речи:**

| Движок | Качество | Скорость | Что нужно |
|---|---|---|---|
| **Piper** | хорошее, нейросеть | очень быстро | ставится сразу + голос ~60 МБ |
| **Silero** | лучшее для русского | медленнее, но терпимо на CPU | PyTorch + модель ~100 МБ (лицензия CC BY-NC) |
| **Голоса Windows** | зависит от голоса (Ирина, Павел…) | быстро | ничего, встроены в систему |

**Умные ударения.** Ударения и буква «ё» расставляются по смыслу предложения: «з**а**мок» и
«зам**о**к», «м**у**ка» и «мук**а**» различаются по контексту. Основано на
[RUAccent](https://github.com/Den4ikAI/ruaccent); словарь хранится в SQLite, поэтому
программа занимает ~600 МБ памяти вместо 1,4 ГБ.

**Подготовка текста:**

- числа словами, раскрытие сокращений (т.е., и т.д., г., км…), символы (№, %, °), транслитерация латиницы;
- словарь произношения с явным ударением (`з+амок`);
- склейка строк, разорванных переносами, и абзацев, разбитых границей страницы.

**Фильтр строк — читать только то, что нужно:**

- автопоиск колонтитулов: строки, повторяющиеся вверху и внизу страниц, находятся сами — «Глава 3 — стр. 15» и «стр. 16» ловятся одним правилом;
- готовые фильтры: номера страниц, ссылки и e-mail, оглавление, сноски, текст в скобках, короткие строки;
- свои правила: «содержит», «начинается с», шаблон, регулярное выражение — убрать строку целиком или только совпадение; наборы правил сохраняются как профили;
- галочка у каждой строки и вкладка «Текст для озвучки» с итоговым текстом и ручной правкой.

**Экспорт аудиокниг:**

- MP3, OGG, FLAC, WAV с выбором качества и тегами названия и исполнителя;
- деление на файлы по главам (оглавление PDF, заголовки Word/ODT/HTML/Markdown, разделы EPUB/FB2, строки «Глава N») и/или по N минут;
- имена вида `Книга 01 - Название главы.mp3`;
- очередь экспорта: несколько книг подряд, у каждой — прогресс и оставшееся время.

**Удобство:** скорость, тон, громкость, паузы между предложениями и абзацами; подсветка
читаемого места; масштаб интерфейса; горячие клавиши.

| Клавиша | Действие |
|---|---|
| `F5` | читать / пауза |
| `F6` | стоп |
| `Ctrl+←` / `Ctrl+→` | абзац назад / вперёд |
| `Ctrl+S` | сохранить аудио |

## Установка

### Обычная установка (для всех)

1. Откройте страницу [**последней версии**](https://github.com/smrplugg/DocVoice/releases/latest)
   и скачайте файл **`DocVoice-Setup-….exe`** из раздела *Assets*.
2. Откройте скачанный файл и нажимайте **«Далее»**. Пароль администратора не нужен.
3. Если появится синее окно *«Система Windows защитила ваш компьютер»*, нажмите
   **«Подробнее»** → **«Выполнить в любом случае»**. Так Windows встречает любую новую
   программу без платной цифровой подписи.
4. На рабочем столе появится значок **DocVoice**. Голоса, Silero и умные ударения уже
   внутри, поэтому интернет после установки не нужен.

Новая версия ставится поверх старой, настройки сохраняются. Удалить программу можно
обычным способом: *Параметры → Приложения*. После установки DocVoice появляется в меню
*«Открыть с помощью»* для PDF, Word, EPUB и FB2, но программу по умолчанию для этих
файлов не меняет.

### Из исходников (для разработчиков)

Нужен Windows и [Python 3.10–3.12](https://www.python.org/downloads/) (при установке отметьте
«Add python.exe to PATH»).

```bat
git clone https://github.com/smrplugg/DocVoice.git
cd DocVoice
install.bat          :: создаст .venv и поставит зависимости
run.bat              :: запуск
```

Или вручную:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py [файл]
```

**Silero (необязательно, самый естественный русский голос):** запустите `install_silero.bat`
(поставит PyTorch для CPU, ~200 МБ), затем в окне **Голоса** → **Silero** скачайте `v5_6_ru`.

**Умные ударения:** **Голоса** → **Умные ударения** → скачать модели (~525 МБ).

> [!TIP]
> Если HuggingFace не открывается, в окне «Голоса» укажите зеркало `https://hf-mirror.com`.

> [!NOTE]
> `.doc` открывается через установленный Word или LibreOffice, DjVu — через `djvutxt`
> (DjVuLibre). Сканированные PDF без текстового слоя нужно сначала распознать (OCR).

## Выпуск новой версии

Установщик собирает GitHub, на своём компьютере ничего собирать не нужно:

1. Поменяйте номер версии в `docvoice/__init__.py` (`__version__ = "1.3.0"`).
2. Отправьте изменения и поставьте тег с тем же номером:

   ```bash
   git commit -am "Версия 1.3.0"
   git tag v1.3.0
   git push && git push --tags
   ```

3. Минут через 30–40 на странице [Releases](https://github.com/smrplugg/DocVoice/releases)
   появится `DocVoice-Setup-1.3.0.exe` с готовой инструкцией по установке.

Как это устроено: [`.github/workflows/build.yml`](.github/workflows/build.yml) ставит
зависимости и PyTorch CPU, скачивает голоса и модели скриптом
[`tools/fetch_models.py`](tools/fetch_models.py) (они кэшируются между сборками),
собирает exe через PyInstaller, прогоняет самопроверку и упаковывает всё в установщик
[Inno Setup](installer/DocVoice.iss). Пробную сборку без релиза можно запустить вручную:
*Actions → Сборка → Run workflow*, установщик появится в артефактах запуска.

Чтобы в сборке с GitHub работала кнопка «Связь с разработчиком», добавьте в
*Settings → Secrets and variables → Actions* секреты `SUPPORT_URL` и `SUPPORT_TOKEN`
(см. [`support/КАК-НАСТРОИТЬ.txt`](support/КАК-НАСТРОИТЬ.txt)).

## Сборка exe вручную

```bat
build_exe.bat
```

Результат — папка `dist\DocVoice` с `DocVoice.exe`. Скрипт сам решает, что включить:

- если в `.venv` есть PyTorch (запускали `install_silero.bat`) — сборка с Silero, около 1 ГБ;
- если нет — лёгкая сборка с Piper и голосами Windows, около 150 МБ.

Голоса и модели из `data/` копируются в сборку автоматически, а ваши настройки и журналы — нет.
В конце собранная программа проходит самопроверку (`DocVoice.exe --selftest`).
Переносить нужно всю папку `dist\DocVoice` целиком: однофайловый exe не делается
намеренно, потому что с PyTorch он распаковывал бы гигабайт при каждом запуске.

Если сборка с Silero не запускается на другом ПК из-за недостающих DLL Visual C++,
запустите `fix_silero_dll.bat` — он доложит их в сборку.

## Помощник на нейросети (экспериментальный, для опытных)

> [!CAUTION]
> **Помощник пока очень сырой.** Это экспериментальная функция: он может ошибаться,
> предлагать лишние или неточные правки, а его поведение сильно зависит от выбранной модели
> и будет меняться от версии к версии. Пользуйтесь им, только если действительно понимаете,
> что делаете, и можете сами оценить каждое предложение, прежде чем применить его.
> Если что-то пошло не так, нажмите «Отменить применённое» или откройте книгу заново.

> [!IMPORTANT]
> **Для обычного чтения книг помощник не нужен**: без него программа работает полностью.
> Настраивайте его, только если знаете, что такое API-ключ (`sk-…`), и уже пользовались
> агрегаторами нейросетей вроде [OpenRouter](https://openrouter.ai), TokenRouter или RouterAI.
> Ключ даёт доступ к вашему балансу у поставщика: не передавайте его посторонним и не
> вводите на чужих компьютерах. Если вы ставите программу родственнику, ключ ему не нужен.

В меню **Помощь → Нейросеть (помощник)…** (пункт виден в режиме «Все настройки») вводятся
адрес сервера в формате OpenAI Chat Completions, ключ и модель. После этого появляется
вкладка **«Помощник»**, которой можно сказать словами:

> «убери ссылки на источники в квадратных скобках», «Гёте читай с ударением на первый слог»,
> «найди главы и назови файлы по ним», «не читай предисловие и примечания»,
> «исправь слипшиеся слова на 12-й странице», «сделай голос помедленнее, паузы между абзацами подлиннее»

**Что умеет помощник:**

- **Сам смотрит книгу.** Перед ответом он может искать по всей книге, открывать строки по
  номерам, проверять, сколько строк заденет правило, смотреть похожие на заголовки строки
  и частые иностранные слова. Поэтому он не угадывает по выборке, а проверяет.
- **Помнит разговор.** Можно уточнять: «нет, только во второй главе». Помощник знает, что
  вы применили из его прошлого ответа, а что отклонили. «Новый разговор» очищает память.
- **Предлагает:** правила очистки, записи словаря произношения, готовые фильтры, разметку
  и названия глав, пропуск кусков книги, правку отдельных строк (было → стало) и настройки:
  голос, скорость, паузы, обработку текста, формат и деление на файлы.
- **Проверяет произношение во всей книге.** Читает книгу частями и предлагает, как читать
  иностранные имена, названия, редкие слова и аббревиатуры. Перед началом показывает,
  сколько будет запросов и примерно сколько токенов.

**Что остаётся неизменным:** нейросеть сама ничего не меняет. Программа проверяет каждое
предложение: компилирует регулярку, считает, сколько строк заденет, показывает примеры,
отбрасывает записи с неверной разметкой ударения. Если правило ничего не находит или номер
строки не тот, она возвращает нейросети замечание, и та исправляется сама. Применяется только
то, что вы отметили, и всё можно отменить. Исправления строк и глав действуют, пока книга открыта.

> [!WARNING]
> Чем больше свободы, тем больше запросов: обычная просьба — 1–4 запроса, а проверка
> произношения — по запросу на каждые ~12 тысяч символов книги, и весь её текст уходит на
> сервер. Качество сильно зависит от модели: слабые бесплатные модели ошибаются в ударениях
> редких имён, поэтому просматривайте предложенное, прежде чем применять.

По умолчанию используется [Numes](https://numes.ai); запасные варианты — Gemini
(бесплатный ключ из AI Studio) и Pollinations (без ключа). Подходит любой сервер
в формате OpenAI Chat Completions, в том числе модели, которые вызывают инструменты через
встроенный механизм `tool_calls`. Ключ хранится локально в `data\settings.json` и в журналы
не попадает. Обычные ударения нейросеть не ставит, это делает RUAccent: на тесте из 62 трудных
случаев он угадал 57 мгновенно, а лучшая бесплатная модель — 47 из 53 по ~26 с на ответ.

## Где что лежит

```
DocVoice/
├── run.py                 точка входа (python run.py [файл] | --selftest)
├── docvoice/
│   ├── extract.py         извлечение текста из всех форматов
│   ├── textproc.py        фильтр строк, сборка абзацев, нормализация текста
│   ├── engines.py         движки: Piper, Silero, голоса Windows (SAPI/OneCore)
│   ├── audio.py           воспроизведение, экспорт, загрузка моделей
│   ├── accent/            умные ударения (на основе RUAccent, MIT)
│   ├── ai.py              помощник: инструменты, проверка предложений, проход по книге
│   ├── selftest.py        самопроверка «всё ли работает»
│   ├── support.py         «Связь с разработчиком»
│   ├── settings.py, log.py, paths.py
│   └── gui/               интерфейс на PySide6
├── support/               Google Apps Script для приёма отчётов о проблемах
├── docs/                  Инструкция (для начинающих) и полное Руководство
├── tools/fetch_models.py  скачивание голосов и моделей для сборки
├── installer/DocVoice.iss установщик (Inno Setup)
├── .github/workflows/     автоматическая сборка и релизы
├── install.bat, install_silero.bat, run.bat
└── build_exe.bat, fix_silero_dll.bat
```

Голоса, модели, настройки и журналы хранятся в папке `data` рядом с программой (её нет
в репозитории). Если туда нельзя писать — в `%LOCALAPPDATA%\DocVoice`; путь можно задать
переменной окружения `DOCVOICE_DATA`.

## Если что-то не работает

- **Помощь → Проверить, всё ли работает** (или `DocVoice.exe --selftest`) проверит папку
  данных, диск, память, звук, MP3, PDF с русским именем, Word, каждый набор голосов и ударения.
- Журнал — `data\logs\docvoice.log`. Личного в нём нет: вместо пути к книге записываются
  только формат и размер файла.
- **Помощь → Связь с разработчиком** отправит комментарий и журнал одной кнопкой.
- Вопросы и ошибки — в [Issues](https://github.com/smrplugg/DocVoice/issues).
